# Hava Nagila Frontend

This is the frontend for the Hava Nagila project, scaffolded with React, Vite, and TypeScript.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Run tests:
   ```bash
   npm test
   ```

## Project Structure

- `src/components`: Reusable UI components.
- `src/pages`: Page components.
- `src/router`: Routing configuration.
- `src/tests`: Unit and integration tests.
