# Hava Nagila

Human-led, AI-powered engineering team project.

## Project Structure

- `frontend/`: React + Vite + TypeScript frontend application.
- `backend/`: (Coming soon) Node.js + TypeScript API.

## CI/CD

We use GitHub Actions for Continuous Integration. The workflow is defined in `.github/workflows/ci.yml`.
It automatically runs linting and tests for both frontend and backend on every push and pull request to the `main` branch.

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

To run tests:
```bash
cd frontend
npm test
```
